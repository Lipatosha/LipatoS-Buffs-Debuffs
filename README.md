# LipatoS — Баффы и дебаффы

Foundry VTT v14 / D&D5e 6.0.6.

Показывает **все активные эффекты** персонажа строкой над портретом; иконки 32×32 пикселя. При наведении — сначала имя эффекта, затем описание.

Сочетается с LipatoS — Нагрузка и показывает её три автоматических эффекта. Во время своего хода выбранный игроком токен получает кнопку «Рывок» (один раз в ход), которая удваивает доступное перемещение за потраченное действие.

**Внимание:** Для автоматических штрафов нагрузки установите также `LipatoS-Encumbrance`. Один лишь этот модуль только отображает эффекты.

Иконки трёх ступеней нагрузки предоставляются отдельным модулем LipatoS — Нагрузка.

## Версия 0.1.1

- Иконки размером 32×32 располагаются нижним краем ровно за 2 пикселя до верхней границы реального портрета. Положение привязано к штатной разметке `.sidebar .portrait`, поэтому остаётся корректным при изменении размеров шапки и окна.
- Вместо «Описание отсутствует» сначала используется собственное описание эффекта, затем описание исходного предмета/особенности/активности, откуда этот эффект был автоматически создан. Поиск производится через стандартные источники D&D5e (`item`, `origin`, `getSource()`), принадлежащие персонажу предметы по совпадающему названию и зарегистрированные системные статусы.
- Всплывающий текст очищается от HTML-разметки. Текст с источника может содержать встроенные ссылки, обрабатываемые штатным TextEditor.enrichHTML.
- Изменение описания предмета обновляет подсказки. Если в доступных источниках текст действительно отсутствует, модуль честно сообщает об этом, не выдумывая описание.
