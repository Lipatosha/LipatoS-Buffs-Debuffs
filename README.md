# LipatoS — Баффы и дебаффы

Foundry VTT v14 / D&D5e 6.0.6.

Показывает **все активные эффекты** персонажа строкой над портретом; иконки 32×32 пикселя. При наведении — сначала имя эффекта, затем описание.

Сочетается с LipatoS — Нагрузка и показывает её три автоматических эффекта. Во время своего хода выбранный игроком токен получает кнопку «Рывок» (один раз в ход), которая удваивает доступное перемещение за потраченное действие.

**Внимание:** Для автоматических штрафов нагрузки установите также `LipatoS-Encumbrance`. Один лишь этот модуль только отображает эффекты.

Иконки трёх дебаффов пока временные, будут заменены предоставленными пользователем.
